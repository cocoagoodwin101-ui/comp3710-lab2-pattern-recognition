B) FULL TEST-SET EVALUATION (all test slices, aggregate DSC)
----------------------------------------------------------------------
On Rangpur:

cd ~/comp3710_lab2
sbatch job_evaluate_test.sh --run_name unet_baseline --checkpoint unet_best.pt
squeue --me

# once finished:
cat unet_testeval_<jobid>.out

This prints per-class DSC averaged across the ENTIRE test set (544
slices, per the earlier folder listing), same PASS/FAIL format as
training used - this is the number to quote if asked "what's your
model's overall test-set performance," distinct from the single-slice
demo number.

This script only prints text, it doesn't save a file on its own -
persist it as a real evidence file before it's lost to a Slurm log
rotation:

cat unet_testeval_<jobid>.out > ~/comp3710_lab2/outputs/unet_baseline/test_set_dsc.txt

Pull that file DIRECTLY into the repo's results folder too
(local PowerShell):

scp s4883100@rangpur.compute.eait.uq.edu.au:~/comp3710_lab2/outputs/unet_baseline/test_set_dsc.txt .
