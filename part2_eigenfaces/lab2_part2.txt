A Random Forest trained on imbalanced classes gravitates toward 
predicting the majority class whenever it's uncertain, since that
minimizes overall error even while completely failing the minority 
class. That's exactly what happened: Bush gets 90% recall (model 
over-predicts him), Sharon gets 0%.

is 62% good? — it's mediocre and directly
limited by (a) using only 150 linear PCA components as features and
(b) a shallow, generic classifier (Random Forest) with no awareness of
spatial structure in the image. This is actually the whole pedagogical 
point of the lab — Part 3 (CNN) is specifically designed to outperform 
this baseline, because CNNs preserve 2D spatial structure and learn 
features end-to-end rather than relying on a fixed linear decomposition 
(PCA) handed to a separate classifier.

Images: 
Compactness plot: Steep rise in the first ~20 components 
(jumping from ~0.2 to ~0.75 cumulative variance), then a long, 
flattening tail out to 150 components, ending around ~0.95. This 
is the classic PCA "elbow" shape, and it's the direct evidence for 
why dimensionality reduction works at all: a huge fraction of the 
meaningful variation across faces is captured by a small number of 
components, and each additional component past ~40-50 adds diminishing 
value. 
If asked "how many components would you need for, say, 90% 
variance," you can read straight off this chart — looks like roughly 
80-90 components gets you there, versus the full 1850 raw pixel 
features. 

Eigenfaces gallery: This matches the lab sheet's reference image well.

Eigenface 0 is notably darker/broader and more face-shaped overall than the 
others — this is expected, since the first principal component 
typically captures the dominant, most common pattern of variation, 
which in face data is usually close to general shading/the average face 
structure.
Eigenfaces 1-3 are still fairly smooth and global (whole-face 
lightness/darkness patterns, broad shape).
Later ones (5, 6, 9, 11) show more localised, higher-frequency detail — 
you can see feature-like structure emerging around eyes/mouth/nose 
regions. Each successive 
eigenface captures progressively finer, more localised variation, 
because SVD orders components by how much variance they explain, from 
most to least. Early components = broad global patterns; later 
components = subtle localised differences. 

This matters because: with only 7 classes and heavy imbalance, a classifier working off 
features that are initially dominated by shared/global patterns has less to latch onto 
for rare classes like Ariel Sharon (13 samples) — it's easier to build a good enough model 
to reliably distinguish the class you see most (Bush, 146 samples) than to also isolate the 
fine feature-level detail (from later eigenfaces) that would properly identify someone you've 
only seen 13 examples of. So the PCA feature quality itself compounds with class imbalance to 
hurt minority classes — not just the classifier's behaviour in isolation.

PCA correctly found a compact, well-ordered basis — you can literally watch identity
information go from broad/global in the early components to fine/localised in the later ones 
— but a linear decomposition plus a generic classifier still tops out at 62% because it has 
no way to prioritise identity-discriminative features over shared appearance patterns, and 
that limitation is compounded by real class imbalance in the dataset itself.

What is the linear decomposition part? It refers to PCA — each eigenface is just a 
weighted sum (linear combination) of the original 1850 pixel values, nothing more complex. 
This is contrasted with a CNN, which can learn non-linear transformations of the input 
(via activation functions between layers), letting it capture more complex relationships 
than a single linear projection ever could.

Recommendation for the imbalanced dataset:  PCA is unsupervised and never 
looks at class labels, so it's completely unaffected by imbalance; the problem lives 
entirely in the classifier stage. The right fixes are class_weight='balanced' on the 
Random Forest (penalising misclassification of rare classes more heavily), 
oversampling/undersampling to balance the training distribution, confirming stratify=y 
was used in the train/test split, and evaluating with macro-averaged F1 rather than raw 
accuracy, since accuracy rewards nailing the majority class while macro-F1 treats every class equally.
